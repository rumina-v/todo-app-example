# React TODO

Учебный проект на React, TypeScript и Vite.

## Возможности

- добавление задач через controlled input;
- переключение статуса и удаление задач;
- отображение прогресса;
- UI-компоненты из `antd`;
- маршруты `/todos`, `/todos/:id` и страница 404;
- функциональные обновления state через `setTodos((prevTodos) => ...)`.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run lint
npm run build
```
